# Student Management System (Java)

This is a simple console-based Java project to manage student records.

## Features
- Add student
- View students
- Search student by ID
- Delete student

## Technologies Used
- Java
- ArrayList
- OOP Concepts

## How to Run
1. Compile:
   javac Main.java

2. Run:
   java Main
